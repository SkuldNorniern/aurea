# aurea-ffi

Rust <-> native ABI declarations for Aurea, and the build of its native layer: Win32 on Windows, AppKit
on macOS, GTK3 on Linux, UIKit on iOS and the NDK on Android.

Apps use [`aurea`](https://docs.rs/aurea), not this crate. Its build requirements are in
[Aurea's README](https://github.com/SkuldNorniern/aurea#building).
